# Contributing

Open a pull request for contributions and use one of the following labels in its title:

- `Spelling fix`
- `Publication`
- `Minor website fix`
- `Major website fix`
- `Content addition`

Please only submit requests for changes you can make yourself. If you cannot implement a requested fix, do not expect someone else to make it for you.

Feel completely free to express yourself to a line in `contributors.txt`
